## 简介

```
给 DeepSeek Harness（DSH）做的开源插件：dsh-workspace-insight。

解决的问题：侧栏只显示工作区的最近状态，工作区一多就记不住——
哪些还在用、哪些该归档、这段时间在忙什么项目。

三个视图：
00:00 问题 & 效果预览
00:20 总览：活跃度 / 耗时 / 建议归档
00:50 月视图：格子里按工作区比例分色
01:20 时间轴：连续日期 × 工作区矩阵
01:50 安装方法 & 隐私说明

安装：dsh plugin --profile web add dsh-workspace-insight
仓库：https://github.com/stone-beka/dsh-workspace-insight
npm：https://www.npmjs.com/package/dsh-workspace-insight
MIT 开源，只读本地数据，不上传。
```

## 30 秒口播（录屏旁白）

> DSH 用久了，侧栏只能看到每个工作区的最近状态。
> 我这边已经有 39 个工作区、400 多条会话，慢慢就记不清：谁还在用、谁该归档、上周在忙什么。
>
> 所以我做了这个插件「工作区洞察」。
> 打开总览，每个工作区最近什么时候用过、跑了多少对话、花了多少时间，一眼看完；超过 20 天没动的，直接标「建议归档」。
>
> 切到月视图，日历里每一格按当天各工作区的对话数分颜色，这一天主要在推进哪个项目，看色块比例就知道。
>
> 再切到时间轴，连续 84 天、40 个工作区的矩阵，周与周之间有线，点开任意一天能看到具体对话，直接跳过去。
>
> 全部只读本地数据，不联网，MIT 开源。装法就一条命令：
> dsh plugin --profile web add dsh-workspace-insight
