# 即刻版

**配图建议**：3 张截图九宫格（总览 / 月视图 / 时间轴）或者一段 10 秒录屏。

---

**文案**：

DSH 用久了，侧栏只能看到每个工作区的「最近状态」，问题就来了：

- 我到底还有多少工作区在活着？
- 上个月我都在忙哪个项目？
- 哪些对话可以放心归档了？

给 DSH 写了个插件 **dsh-workspace-insight（工作区洞察）**，把这三件事一次解决：

📊 **总览**：39 个工作区摊开看，谁几天前用过、谁 20 天没动该归档一眼就知道
🗓 **月视图**：日历格子里按工作区比例分彩条，这一天谁在干活看得明明白白
📈 **时间轴**：连续 84 天 × 40 个工作区的矩阵，周与周之间画线，像 GitHub 贡献图

全部只读本地数据，不上传、不联网，MIT 开源。

安装一条命令：
`dsh plugin --profile web add dsh-workspace-insight`

仓库 👉 https://github.com/stone-beka/dsh-workspace-insight

（顺手做了「建议归档」标记和一键归档，终于不用在侧栏里一个个翻了。）
